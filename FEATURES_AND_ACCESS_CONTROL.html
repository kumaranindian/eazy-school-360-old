👥 User Roles & Permissions

SUPER ADMIN
System-wide administrator with full access to all features across all schools.
Access: Full read/write/delete access to all collections and features
Scope: All schools in the system
ADMIN (Also: TENANT_ADMIN)
School administrator with full access to their school's data and features.
Access: Full management of staff, students, finance, academic years, promotions
Scope: Single school (their assigned school only)
Can: Approve leaves, manage payroll, configure settings, promote students
FINANCE (Also: USER, ACCOUNTS)
Finance department user with access to financial operations and student fee management.
Access: Student fees, bills, expenses, fee structures, arrears, financial reports
Scope: Single school (their assigned school only)
Cannot: Manage staff, approve leaves, configure policies, promote students
STAFF (Also: TEACHER)
Teaching and non-teaching staff with access to their own data and class teacher features.
Access: Own profile, apply for leaves/permissions, view students (if class teacher)
Class Teacher: Can approve student leave requests for their assigned class
Scope: Own data + assigned class (if class teacher)

📅 Academic Year Management NEW

Academic Year Configuration
Manage academic years (May-April) and fiscal years (April-March) for the school.
Read: SUPER ADMIN ADMIN FINANCE STAFF
Create/Update: SUPER ADMIN ADMIN
Delete: SUPER ADMIN ADMIN
Features:
  • Initialize academic years (creates 5 years: -2, -1, current, +1, +2)
  • Set current academic/fiscal year
  • Auto-detect current year based on date
  • View year date ranges
  • Run data migration for existing schools
Data Migration
Migrate existing school data to support academic year system.
Execute: SUPER ADMIN ADMIN
Migration Steps:
  • Assign current academic year to all existing students
  • Assign academic year to fee structures
  • Assign fiscal year to bills
  • Verify migration completion

🎓 Student Promotion NEW

Class-wise Student Promotion
Promote students from one class to the next with automatic arrears calculation and carry-forward.
Execute: SUPER ADMIN ADMIN
Features:
  • Single student promotion
  • Bulk class promotion (all students in a class-section)
  • School-wide promotion (all classes)
  • Automatic class progression (Pre-KG → LKG → ... → XII → GRADUATED)
  • Calculate pending fees as arrears
  • Create arrears records automatically
  • Update student academic year
  • View promotion summary with arrears created
Arrears Management
Track and manage pending fees carried forward from previous academic years.
Read: SUPER ADMIN ADMIN FINANCE
Create/Update: SUPER ADMIN ADMIN FINANCE
Delete: SUPER ADMIN ADMIN
Arrears Features:
  • Automatic calculation during promotion
  • Track arrears status (PENDING, PAID, PARTIALLY_PAID, WAIVED)
  • Record payments towards arrears
  • Waive arrears with reason
  • View arrears history per student
  • Bulk arrears creation for class/school

🗄️ Firestore Collections & Security

New Collections (Academic Year System)

schools/{schoolId}/academicYears
Stores academic year records (May-April cycle)
Read: All authenticated users in the school
Write: SUPER_ADMIN, ADMIN only
schools/{schoolId}/fiscalYears
Stores fiscal year records (April-March cycle)
Read: All authenticated users in the school
Write: SUPER_ADMIN, ADMIN only
schools/{schoolId}/arrears
Tracks pending fees carried forward from previous years
Read: SUPER_ADMIN, ADMIN, FINANCE
Write: SUPER_ADMIN, ADMIN, FINANCE
schools/{schoolId}/studentLeaves
Student leave requests and approvals
Read: SUPER_ADMIN, ADMIN, STAFF (class teacher)
Write: SUPER_ADMIN, ADMIN, STAFF (class teacher for approval)
