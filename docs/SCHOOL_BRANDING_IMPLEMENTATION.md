# School Branding Implementation for PDFs and Reports

## Overview
School details from the Settings page are now automatically used in all PDF bills and reports throughout the application. The system fetches school information (name, address, phone, email, website, logo) from Firestore and applies consistent branding across all generated documents.

## Implementation Details

### 1. School Entity (`lib/domain/entities/school.dart`)
The `School` entity already includes all necessary branding fields:
- `schoolName` - School name
- `address` - School address
- `phone` - Contact phone number
- `email` - Contact email
- `website` - School website
- `logoUrl` - School logo URL

### 2. PDF Branding System (`lib/presentation/shared/pdf/pdf_branding.dart`)
Centralized branding system that:
- Fetches school details from Firestore
- Caches branding data in memory for performance
- Provides reusable header and footer widgets
- Handles missing data gracefully with sensible defaults

**Key Methods:**
```dart
// Fetch school branding (cached)
final branding = await PdfBranding.forSchool(schoolId);

// Build PDF header with school details
PdfBranding.buildHeader(branding, title: 'Fee Receipt', subtitle: 'Academic Year 2024-25')

// Build PDF footer
PdfBranding.buildFooter(branding, pdfContext)
```

### 3. Updated Services

#### Payslip PDF Service (`lib/data/services/payslip_pdf_service.dart`)
**Changes:**
- Updated to use `PdfBranding` instead of hardcoded school name
- Now displays school logo, address, phone, and email on payslips
- Signature changed from `schoolName: String` to `schoolId: String` parameter

**Before:**
```dart
await PayslipPdfService.downloadSinglePayslip(record, schoolName: 'Eazy School 360');
```

**After:**
```dart
await PayslipPdfService.downloadSinglePayslip(record, schoolId: session.schoolId!);
```

#### Fee Receipt Generation (`lib/presentation/finance/screens/student_fee_management_screen.dart`)
Already uses `PdfBranding.forSchool()` - no changes needed.

#### Financial Reports (`lib/presentation/finance/screens/financial_reports_screen.dart`)
Already uses `PdfBranding.buildHeader()` and `PdfBranding.buildFooter()` - no changes needed.

### 4. Updated Screens

#### Staff Payslips Screen (`lib/presentation/staff/screens/my_payslips_screen.dart`)
- Updated to pass `schoolId` when downloading payslips
- Session parameter passed to `_buildPayslipCard` method

#### Payroll Management Screen (`lib/presentation/admin/screens/payroll_management_screen.dart`)
- Updated bulk payslip download to use `schoolId`
- Updated single payslip download to use `schoolId`
- Session parameter passed to `_showPayslipDetailDialog` method

## How to Update School Details

1. Navigate to **Settings** page in the admin dashboard
2. Update the following fields:
   - School Name
   - Address
   - Phone
   - Email
   - Website
3. Click **Save**

The changes will be automatically reflected in all future PDF generations.

## PDF Header Format

All PDFs now include a consistent header with:
- School logo (if available)
- School name (bold, prominent)
- School address
- Contact information (phone and email)
- Document title and subtitle (right-aligned)

## PDF Footer Format

All PDFs include a consistent footer with:
- "Generated by EazySchool 360" text
- Page numbers (e.g., "Page 1 of 3")

## Cache Management

The branding system caches school details in memory to avoid repeated Firestore calls. To clear the cache (e.g., after updating school settings):

```dart
PdfBranding.clearCache();
```

**Note:** The cache is automatically cleared when the app restarts.
